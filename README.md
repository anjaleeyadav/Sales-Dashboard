# Sales-Dashboard
1. Project / Headline  
📊 Sales Analytics: India Hardware Sales Insights Dashboard

A dynamic, interactive data visualization tool built to explore
hardware sales data across Indian states, brands, product
categories, and supervisors — focusing on regional comparisons,
revenue performance, brand contribution, and supervisor-level
accountability.

2. Short Description / Purpose

The Sales Analytics Dashboard is a visually engaging and 
analytical Power BI report designed to help users explore 
and compare hardware product sales across multiple Indian 
states 🗺️, 11 brands 🏷️, and 13 product categories 📦 
for the fiscal year 2022-23.

The dashboard focuses on highlighting major sales metrics 
like total revenue 💰, profit margins 📈, category-wise 
quantity, brand-wise sales share, and supervisor-level 
performance 👤.

This tool is intended for use by sales managers 👔, 
business analysts 📊, procurement teams 🛒, and regional 
supervisors who seek to understand revenue trends, brand 
performance, and territory-level sales insights — all in 
a single interactive view ✅.

3. Tech Stack

- 📊 Power BI Desktop – Report creation & dashboard design.

- 📂 Power Query – Data cleaning & transformation.

- 🧠 DAX – Calculated measures & KPI cards.

- 🔗 Data Modeling (Star Schema) – 3 tables connected:
  Sales_Data, State_list, Supervisor.

- 🗺️ Bing Maps – State-wise sales map across India.

4. Features / Highlights

- Business Problem
Hardware sales teams lack a unified view to track
performance across regions, brands & supervisors.

- Goal
To build an interactive tool that helps:
- Monitor KPIs in real time 📊
- Analyze brand & category trends 🏷️
- Track supervisor performance 👤
- Identify underperforming states 🗺️

  before peak season.

  Low share brands → review or replace.
